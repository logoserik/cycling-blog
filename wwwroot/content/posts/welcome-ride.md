This is the sample ride post that ships with the Sveltia conversion.

## What changed

- Posts are Markdown files in the repo (`wwwroot/content/posts`)
- Photos upload into `wwwroot/uploads` and appear in the body as Markdown images
- Publishing is a GitHub commit; GitHub Actions rebuilds the site

## Add a photo

In the CMS admin, edit this post, click the image control in the Markdown editor, upload a file, then publish.
